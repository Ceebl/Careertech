Using it

Two lines. The class on body is what opts a page in.

<link rel="stylesheet" href="/brand/ct.css">

<body class="ct-page">

Add the script too if the page wants the light/dark toggle. It goes in <head> without defer, so a saved dark setting is applied before anything is drawn. 

<script src="/brand/ct.js"></script>

For a block that lives inside someone else's page, use ct-root instead. It carries the same styling but touches nothing outside itself. 

<div class="ct-root"> … </div>
Code produced by a builder does not use this file. Anything a tool generates for pasting elsewhere carries its own styles, so it can never break when this stylesheet changes or the server is unreachable.

Buttons

One solid primary per screen. Everything else is outlined, plain or quiet.

<button class="ct-btn ct-btn--primary">Primary action</button>
<button class="ct-btn ct-btn--outline">Outlined</button>

Forms

Every field gets a label with a for attribute. No exceptions — it is what makes the label clickable and readable by a screen reader.

A hint sits under the field, not inside it.
Pick a colour 
<div class="ct-field">
  <label class="ct-label" for="url">Text field</label>
  <input class="ct-input" id="url" type="text">
  <span class="ct-hint">A hint.</span>
</div>

Notes

Each one carries an icon and a word, so colour is never the only signal.

Careful: something needs attention but nothing has broken.
Problem: it has broken, and here is what to do about it.
Done: it worked.

Rules

  • No pill shapesExcept tag chips. Rounded rectangles everywhere else — 8px on controls, 14px on cards.
  • Colour is never the only signalEvery status carries an icon and a word as well, because two of the palette colours look alike to colourblind readers.
  • One solid primary button per screenIf everything shouts, nothing does.
  • Sentence caseIn buttons, headings and labels. Not Title Case, not SHOUTING.
  • Nothing loads from anyone else's serverFonts are hosted here. No third-party images in tool chrome.
  • Every page carries a viewport tag<meta name="viewport" content="width=device-width, initial-scale=1"> — without it a phone renders the page at desktop width and shrinks it.
