Hosting and embedding your widget

These widgets use JavaScript, so they cannot be pasted straight into a TargetConnect description box — those editors strip code out for security. The generated file has to be hosted somewhere first.

Option 1: ask your IT team

  1. Click Copy snippet.
  2. Paste it into Notepad or TextEdit and save as my-widget.html.
  3. Send the file to your IT or web team and ask them to host it.
  4. They give you back a URL.
  5. Embed that URL in TargetConnect or SharePoint using an iframe.

Option 2: GitHub Pages, free

  1. Create a free account at github.com.
  2. Create a repository named something like careers-tools.
  3. Choose Add file › Create new file.
  4. Name it flashcards.html, paste your code in, and commit.
  5. Go to Settings › Pages.
  6. Under Source pick the main branch and save.
  7. A few minutes later it is live at https://your-username.github.io/careers-tools/flashcards.html
