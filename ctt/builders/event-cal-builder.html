Style and data

Required TargetConnect setup. In your RSS settings, tick Show field name for Title, Event Type, Brief Description, Location, Closest Future Date and End Date. Without those the calendar cannot read your events.

Saving and hosting

  1. Copy the code from the right.
  2. Paste it into Notepad or TextEdit and save it as index.html.
  3. Host that file on a secure (HTTPS) web server or GitHub Pages.

Your IT team is usually the right people to ask about hosting.

About the feed relay. A browser cannot read another site’s RSS feed directly, so this widget goes through the free public relay rss2json.com. It rate-limits and occasionally goes offline. Fine for a screen in a foyer; run your own feed proxy for anything people depend on.
