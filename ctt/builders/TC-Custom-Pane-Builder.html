How to use the Custom Pane Maker

This builds responsive HTML banners with Velocity logic, so students see different content based on their tags. Every template uses table-based layout, which stops the platform’s own CSS from breaking the buttons.

1. Audience rules

The tool writes IF / ELSE IF / ELSE logic. Rules are checked in order and the first match wins.

  • Target tags are comma separated and behave as AND. Typing Business School, Final Year means a student needs both tags.
  • Aim for about 15 rule groups at most, for the platform’s sake.
Tag checks are case sensitive. Type them exactly as they appear in your platform — Business will not match business.

2. Styles

  • Modern — clean box with a soft shadow, good for announcements.
  • Important notice — bold border, for urgent deadlines.
  • Professional — squared edges, for formal announcements.
  • Gradient — a sweep between your two colours.
  • Custom image banner — your own graphic, with buttons underneath. Leave the headline blank to show only the image.

3. The fallback

Students matching none of the rules above see the fallback banner. Leave its headline blank if you would rather show nothing.

4. Buttons and links

Up to three buttons each. The dropdown covers the common internal platform pages; choose Custom URL to enter your own.

5. Using the code

Check the preview, click Copy Velocity code, and paste the whole thing into the HTML editor of a Custom Pane on the staff dashboard.
