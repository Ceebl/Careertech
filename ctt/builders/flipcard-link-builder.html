How this works

The usual problem with these widgets is that they need a file hosted somewhere, and plenty of universities will not let their careers teams host files. This one removes that step entirely.

The flip card page itself is hosted once, here. Your cards are not stored anywhere — they are squashed down and packed into the link. When someone opens it, their browser unpacks the cards and shows them. That is why the link is so long, and why there is nothing for you to upload.

Using it

  1. Write your cards on the left.
  2. Click Copy embed code.
  3. Paste it into TargetConnect, SharePoint, Moodle or your CMS, anywhere that accepts an embed or iframe.

Worth knowing

  • Nothing is stored. The part of the link after the # never leaves the browser, so your card content is never sent to this server and never appears in any log here.
  • To change a card later, paste your link back into the box at the bottom left, edit it, and swap the link over.
  • Keep the whole link. If it gets cut short in an email or a text box, it will not open. The page will say so rather than showing half a deck.
  • It needs this site to be up. The page is served from here, so if this server is down the embed shows an empty box.
  • Do not put personal information in the cards. Anyone with the link can read everything in it.

Running your own copy

Both this builder and the flip card page are plain HTML files with no server behind them, so they will sit on any hosting that serves static files — Kinsta, GitHub Pages, SharePoint, a university web server, anything. There is nothing to install and no database.

Copy this folder structure across, keeping the shape:

brand/ct.css
brand/ct.js
builders/flipcard-link-builder.html
w/flipcards/index.html

The builder looks for a copy of the flip card page alongside itself when it loads. If it finds one, your links point at your own hosting and you are entirely independent. If it does not, they point back at the original. Either way the address it settled on is shown at the bottom of the settings, and you can type a different one in.

If you only want the flip card page and not the builder, that single file is all you need — build links here and change the address to yours.

Making it fit the page

An embedded frame cannot grow to fit its contents on its own, so the embed code sets a fixed height based on your card height. If your web team can add a small script to the host page, the widget sends its real height as a message (flipcards:height) that they can listen for.
