VAC

Vacancies List Widget Maker

A job board built from your vacancies feed.

Universal edition

Data and integration

Required feed setup. In your Vacancies RSS settings, tick Show field name for Type of Opportunity, Employer Name, Details and Expiry Date.
Feed limits. Without a key the feed shows at most 10 items.

Styling and layout

Card border and employer icon

Category tabs

Finding your opportunity types. Tabs match on the Opportunity Types you define. In your careers platform go to Maintenance › Manage Lists › Job Related Lists › Opportunity types and read the Description column. Matching ignores capitalisation.
Anything not matching a custom tab lands here.

Hosting and embedding

  1. Copy the code below and save it as vacancies-widget.html.
  2. Host it over HTTPS on your web server or GitHub Pages.
  3. Embed it anywhere with an iframe.
<iframe src="YOUR_HOSTED_URL" width="100%" height="550" frameborder="0"></iframe>
About the feed relay. A browser cannot read another site’s RSS feed directly, so this widget goes through the free public relay rss2json.com. It rate-limits and occasionally goes offline. Fine for a screen in a foyer; run your own feed proxy for anything people depend on.

Going past the 10-item limit

This widget uses a free service called RSS2JSON to turn the feed into clean data. Anonymous requests are capped at 10 items to save their bandwidth.

  1. Sign up for a free account at rss2json.com.
  2. Open My Account and find your API key.
  3. Copy it.
  4. Tick Use an API key in this builder and paste it in.
You can restrict the key on the RSS2JSON site so it only works on your own GitHub Pages and careers platform addresses.
