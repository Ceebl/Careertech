CareerTech Tools

Small, free tools for careers services — generic versions of things built for one service and shared with the TargetConnect community. Every one of them is a single page that runs entirely in your browser. Nothing is uploaded, stored or tracked.

Widget builders

Each of these generates a self-contained HTML file you can host yourself and embed anywhere — TargetConnect, SharePoint, Canvas, Blackboard.

  • Universal Widget Maker The general-purpose one. Start here. →
  • Custom Pane Maker Build a styled TargetConnect content pane. →
  • Event Template Builder Lay out a single event page. →
  • Event Calendar Maker Calendar view of an events feed. →
  • Events RSS List Widget Maker Scrolling list of upcoming events. →
  • Vacancies List Widget Maker Live vacancy list from a feed. →
  • Pure CSS Modal Maker Pop-up dialogs with no JavaScript at all. →
  • QR Code Maker Colour-customisable QR codes, transparent background optional. →

The three feed-driven builders read RSS through a free public relay, which rate-limits and sometimes goes down. Fine for a screen in a foyer; host your own proxy for anything critical.
