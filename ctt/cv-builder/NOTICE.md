# About this build

This folder is a customised, self-contained build of
[Reactive Resume](https://github.com/AmruthPillai/Reactive-Resume) by Amruth Pillai,
used under the MIT licence (see `LICENSE`).

It runs entirely in the browser -- there is no account, no server and no database.
Everything a visitor types stays on their own device.

Branding is driven by `config.json`: set `institutionName`, `institutionUrl`,
the `logo` paths and `colors` to match your own service. Leaving them blank,
as they are now, gives the neutral default.

This is not the official hosted version. For that, and for the source code,
see https://rxresu.me.
