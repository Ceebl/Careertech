Interactive activities when IT will not let you host files

Plenty of careers teams cannot upload anything to a web server. These widgets remove that step. The page is hosted here once; everything you write travels inside the link. You paste an iframe and you are done.

1 Write your content In the builder, with a live preview beside you.
2 Copy the embed code One iframe tag, already sized.
3 Paste it anywhere TargetConnect, SharePoint, Canvas, Blackboard, Moodle.

Your content sits after the # in the link, and that part never leaves the browser — it is never sent to this server and never appears in any log here. The trade is that the embed needs this site to be up. If that is a problem, take a copy: every file is plain HTML that will sit on any static hosting.

Guess & Reveal

Students commit to an answer before they see the truth. The gap between what they expected and what is real is what makes the point stick — far better than simply telling them.

  • Myth-busting: the hidden job market, application volumes, salary reality
  • Judging a sample interview answer, CV line or email out of five
  • Showing what last year’s cohort said, from your own survey data

Flip Cards

Being built next

Same pattern, same three steps. Nothing here is ready yet — it is listed so you know what is coming rather than building a workaround for it.

  • Card sort — rank or bucket a set of cards
  • Scenario tree — choices with consequences
  • Self-assessment sliders — rate yourself, get a profile
  • Action plan builder — prompts in, formatted text out
  • Checklist — tickable prep list with a progress bar
  • Step-by-step timeline — one panel at a time

Using these in a TargetConnect Pathway. Nothing is sent anywhere, so a widget cannot report a score back on its own. Where it matters, turn on the option that gives students their answers as text to copy, and pair the embed with a reflection or evidence field in the same activity. TargetConnect does the recording; the widget does the thinking.

Take these, change them, use them. Every builder and every widget page is a single HTML file with no server behind it.
