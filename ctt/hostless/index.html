Interactive activities when IT will not let you host files

Plenty of careers teams cannot upload anything to a web server. These tools remove that step. You write your content, copy what comes out, and paste it where you want it. There is nothing to upload and no account to create.

1 Write your content In the builder, with a live preview beside you.
2 Copy what it gives you A block of code, or a ready-made iframe tag.
3 Paste it anywhere TargetConnect, SharePoint, Canvas, Blackboard, Moodle.

They come in two kinds, and the difference matters. One kind gives you a block of code that is the whole thing — it depends on nobody, including us. The other kind gives you a link to a page we host, with your content packed inside the link itself; those are editable later and can do far more, but they need this site to be up. If that is a problem, take a copy: every file is plain HTML that will sit on any static hosting.

Paste the code — nothing hosted at all

What you copy is the entire thing: markup and styling, no JavaScript, nothing loaded from anywhere. Paste it into a Pathway activity and it keeps working whatever happens to this site. The trade is that you cannot edit it afterwards from here — to change it you build a new one and swap the code over.

Pop-up Modal

A button that opens a dialog over the page. Uses a hidden checkbox instead of JavaScript, so it survives the security filters that strip scripts out of most LMS and CRM platforms.

  • A tip or an aside that would clutter the activity if left on the page
  • Terms, eligibility notes, the long version of a short answer
  • Anywhere you want detail available without making everyone read it

Worth knowing before you use one: the Escape key will not close it, and focus is not held inside the dialog. Both need JavaScript. For a tip that is fine; for something a student must read, put it on the page instead.

Paste a link — we host the page

Your content is squashed down and packed into the link itself, after the # — a part of a web address that never leaves the browser, so it is never sent to this server and never appears in any log here. You paste an iframe. These can be edited later by pasting the link back into the builder.

Guess & Reveal

Being built next

Same pattern, same three steps. Nothing here is ready yet — it is listed so you know what is coming rather than building a workaround for it.

  • Card sort — rank or bucket a set of cards
  • Scenario tree — choices with consequences
  • Self-assessment sliders — rate yourself, get a profile
  • Action plan builder — prompts in, formatted text out
  • Checklist — tickable prep list with a progress bar
  • Step-by-step timeline — one panel at a time

Using these in a TargetConnect Pathway. Nothing is sent anywhere, so a widget cannot report a score back on its own. Where it matters, turn on the option that gives students their answers as text to copy, and pair the embed with a reflection or evidence field in the same activity. TargetConnect does the recording; the widget does the thinking.

Take these, change them, use them. Every builder and every widget page is a single HTML file with no server behind it.
